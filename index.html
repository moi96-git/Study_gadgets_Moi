Toolbox: the maths you need, and what carries over from Units 1–2

You need exactly four maths skills for Unit 3. If one of them feels shaky, fix it here, because every later module leans on it.

Skill 1 · Derivatives of powers

A derivative tells you the slope: how much the output changes when you nudge the input by a tiny amount. In economics, “marginal” always means “a derivative”.

Power rule: d/dx [ xn ] = n · xn−1 x² → 2x x³ → 3x² √x = x1/2 → ½ · x−1/2 = 1/(2√x) constant → 0 a·x → a (a constant multiplier just comes along)

Numbers. Take total cost C(q) = 8 + 2q + q². Then the marginal cost is C′(q) = 2 + 2q. The 8 disappears because it never changes with q. That one fact (fixed costs vanish when you differentiate) will win you points in this unit.

Skill 2 · Partial derivatives

A production function has two inputs, q = √(LK). A partial derivative moves one input and freezes the other. Treat the frozen one as if it were a plain number.

q = (LK)1/2 = L1/2 K1/2 MPL = ∂q/∂L = ½ L−1/2 K1/2 = ½ √(K/L) (K is frozen) MPK = ∂q/∂K = ½ √(L/K) (L is frozen) ratio: MPL / MPK = K / L

Numbers. At L = 4, K = 16: MPL = ½ √(16/4) = ½·2 = 1, and MPK = ½ √(4/16) = ½·½ = ¼. Ratio = 4 = K/L ✓.

Skill 3 · Optimising with one variable

Analogy

You are hiking up a hill in fog. You cannot see the top, but you can feel the slope under your feet. While the slope is positive you keep climbing. The moment it is zero you are at a flat spot. If the ground curves downward around you, that flat spot is a summit, not a valley.

Step 1 (first-order condition, FOC): set the derivative to zero. π′(q) = 0 Step 2 (second-order condition, SOC): check the curvature. π″(q) < 0 ⇒ maximum Example: π(q) = 8q − 2q² ⇒ π′ = 8 − 4q = 0 ⇒ q* = 2, π″ = −4 < 0 ✓ π(2) = 16 − 8 = 8

Try it. Slide q and watch the slope. The tangent line is flat exactly at the top.

Skill 4 · Marginal versus average

Analogy

Your class average is 7. A new student joins and scores 9. The average goes up. If she scores 5, the average goes down. The newcomer is the marginal value, and the class mean is the average. The average rises when the marginal is above it, falls when it is below, and sits still when they are equal.

d(AC)/dq = ( MC − AC ) / q MC > AC ⇒ AC rising MC < AC ⇒ AC falling MC = AC at the minimum of AC Same logic: MPL vs APL and MC vs AVC

This one sentence explains why the marginal cost curve cuts the average cost curve at its lowest point. You will see it happen in Module 5.

Module 2

Production: turning inputs into output

A firm takes inputs (labour L, capital K) and, using some technology, produces output q. The production function is the recipe that links them:

q = f(L, K) L = labour services (worker-hours) K = capital services (machine-hours)

It reports the maximum output you can get from a bundle of inputs. A real firm may produce less (downtime, waste), but the function is the frontier of what is possible.

Analogy

A topographic map. Each point on the floor is a bundle of inputs (L, K). The altitude at that point is the output q. An isoquant is a contour line: all the bundles at the same altitude. Walk along it and output does not change. Walk to a higher contour and you produce more.

Isoquants

For q = √(LK), the isoquant at output 4 solves √(LK) = 4, so LK = 16, or K = 16/L. Three bundles on it: (2, 8), (4, 4), (8, 2). Check: 2·8 = 16 ✓. More labour can compensate for less capital. The general isoquant is LK = q².

Two different experiments

Diminishing marginal product changes one input and holds the other fixed. Returns to scale changes all inputs in proportion. For √(LK): doubling only L gives √2 ≈ 1.41 times the output. Doubling both gives exactly 2 times. Both statements are true at once, so they are never in conflict.

Reading production data without fooling yourself

Bakery A makes 100 loaves with L = 10, K = 4. Bakery B makes 160 with L = 10, K = 16. B’s output per worker is 16 versus 10. Does B have better technology? Not necessarily. B also has four times the capital. Higher output per worker can simply mean more machines per worker. And two snapshots of different bakeries do not give a marginal product, which needs a change in labour holding capital and technology fixed.

Module 3

The cheapest way to produce a given quantity

The isoquant tells you what is feasible. Prices tell you what it costs. Hire labour at wage w, rent capital at r, and the expenditure is wL + rK.

Isocost lines

All bundles with the same spending c satisfy wL + rK = c. Solve for K: K = c/r − (w/r)·L. A straight line with slope −w/r. That slope is the market’s exchange rate: to hire one more unit of labour you must give up w/r units of capital. Lower parallel lines are cheaper.

Analogy

You are shopping for a fixed amount of “output” with two ingredients. The isocost line is the shopkeeper’s price list: “one labour hour costs four machine-hours”. The isoquant is the recipe’s flexibility: “the dish works with less machine if you add labour”. The cheapest dish is where the shopkeeper’s exchange rate equals the recipe’s exchange rate. That is the tangency.

The three-step recipe (memorise this)

Step 1 Tangency fixes the proportions: MRTS = w/r (for √(LK): K/L = w/r) Step 2 The output target fixes the size: f(L, K) = q̄ (for √(LK): LK = q̄²) Step 3 Price the bundle: C = wL + rK
Trap

Tangency alone gives a ratio (K = 4L), never a quantity. You must use the output target to find L and K. Many lost points live here.

The formula to remember for √(LK)

K/L = w/r and LK = q² ⇒ Lc(q) = q·√(r/w), Kc(q) = q·√(w/r), C(q) = 2q·√(w·r) check (w = 4, r = 1, q = 4): L = 4·½ = 2, K = 4·2 = 8, C = 2·4·√4 = 16 ✓

“Conditional” means the output target is held fixed. If w rises, Lc falls and Kc rises.

Why it is the cheapest: marginal product per euro

Rewrite the tangency as MPL/w = MPK/r. Each side is the extra output from one more euro spent on that input. Suppose MPL/w = 3 and MPK/r = 1. Move a euro from capital to labour: you lose 1 unit of output but gain 3, at the same cost. So the old mix was not optimal. At the optimum no such gain is left.

With a Lagrangian ℒ = wL + rK + μ[q − f(L,K)] the conditions are w = μ·MPL, r = μ·MPK, f = q. Divide the first two to get MRTS = w/r. And μ = MC: it measures how much cost rises if you ask for one more unit of output (just like μ was the value of an extra euro of income in Unit 1).

When tangency fails: corners and kinks

Perfect substitutes

q = L + K. One input replaces the other at a constant rate. Use the cheaper one only. With w = 2, r = 1 and q = 12: L = 0, K = 12, cost 12. At a corner the “equal MP per euro” rule is not needed, because an unused input has nothing to equalise. If w = r, every mix on the line costs the same.

Perfect complements

q = min{L, K}. You need both together. The optimum sits at the kink L = K = q. A higher wage raises cost but does not change the mix. With w = 3, r = 2, q = 12: cost 3·12 + 2·12 = 60.

General rule: choose the cheapest feasible bundle. Tangency is just how that rule looks when everything is smooth.

Exam shortcut for linear technologies

For q = aL + bK, compare output per euro: a/w versus b/r. Use the input with the larger ratio and none of the other. Example: q = 2L + K, w = 3, r = 2. Labour gives 2/3 ≈ 0.67 per euro, capital 1/2 = 0.5 per euro, so use labour only: L = 6 for q = 12, cost 18.

Module 4

From the cost function to how much to produce

Step 1 of the firm’s problem gave a cost function C(q): the lowest possible cost of each output level. Now step 2: choose the output with the highest profit.

π(q) = p·q − C(q) MC(q) = C′(q) (price taker: p is given, the firm is too small to move it)

Why p = MC

One more unit earns p and costs about MC. If p > MC, produce more: profit rises. If p < MC, produce less. At a smooth interior optimum p = MC(q*).

Three checks before you write “q* = …”

1. Is it a maximum? MC must be rising there (π″ = −MC′ < 0).
2. Is profit better than zero output? Compare π(q*) with π(0).
3. Is there a capacity limit? Then the answer may be a corner.

Worked example: the whole firm problem

Technology q = (LK)1/4, w = r = 1, price p = 8.

1

Cheapest inputs. MRTS = K/L = w/r = 1, so K = L. Target: LK = q⁴, so L² = q⁴ and Lc = Kc = q².

2

Cost. C(q) = 1·q² + 1·q² = 2q². So MC(q) = 4q. Doubling output needs four times the inputs. That is why MC rises.

3

Output. p = MC: 8 = 4q, so q* = 2. SOC: π″ = −4 < 0 ✓.

4

Inputs. L* = K* = q*² = 4.

5

Profit. π = 8·2 − (4 + 4) = 8, and π(0) = 0, so producing wins.

Cross-check with the one-step method. Maximise p·f(L,K) − wL − rK directly. First-order conditions: p·MPL = w and p·MPK = r. For (LK)1/4: MPL = q/(4L), so 8·q/(4L) = 1 gives L = 2q. Same for K. Then q⁴ = LK = 4q² gives q = 2, L = K = 4. Same answer ✓.

The general version (useful for “what if prices change?”)

q = (LK)1/4: Lc = q²·√(r/w), Kc = q²·√(w/r), C(q) = 2q²·√(wr), MC = 4q·√(wr) p = MC ⇒ q* = p / (4√(wr)) profit π* = p² / (8√(wr)) check (p = 8, w = r = 1): q* = 8/4 = 2 ✓, π* = 64/8 = 8 ✓

Why two steps?

Step 1 uses technology and input prices, and it never needs the selling price. Step 2 adds the output price. If p drops from 12 to 8 (Exercise 4), the cost function C(q) = 2q² does not change at all. Only the choice along it changes: q* moves from 3 to 2.

Module 5

Short-run costs: when capital is stuck

So far both inputs could change. That is the long run. In the short run capital is fixed at K̄ and only labour adjusts.

Analogy

A bakery can call in more staff tomorrow, but it cannot build a second oven tomorrow. Extra bakers crowd around the same oven and each adds less than the last. “Long run” does not mean “many months”. It means enough time to change all the inputs in the model.

From fixed capital to costs

With q = √(L·K̄), there is nothing to optimise between inputs. The target dictates the labour:

q = √(L·K̄) ⇒ L(q) = q² / K̄ Fixed cost F = r·K̄ (the capital payment is due even at q = 0) Variable cost VC(q) = w·q² / K̄ Total cost CSR(q) = F + VC(q) = r·K̄ + w·q²/K̄

Doubling output from 4 to 8 needs four times the labour, because capital cannot expand with it. That is why the labour bill grows faster than output.

Trap

Fixed cost moves AC, but not MC or AVC. If the committed rent rises by ΔF, AC rises by ΔF/q at each q. The cost of producing one more unit is unchanged, so the firm’s output choice today does not change.

Technology versus “more capital”

With q = √(LK): at L = 4, K = 4 → q = 4 (APL = 1). At L = 4, K = 9 → q = 6 (APL = 1.5). More capital raises output per worker and MPL, but it lowers APK. That is movement to a different input mix, not better technology. Technological progress is a shift of the production curve: q = A√(LK) with A rising from 1 to 1.5 gives more output from the same inputs.

Analogy

You bought a non-refundable concert ticket (sunk). Should you go on the night? The ticket price is gone either way, so only today’s costs and benefits matter. But before you buy next year’s ticket, the price is avoidable, so you buy only if the concert is worth it.

The short-run shutdown rule

Suppose the fixed cost F must be paid even if the firm stops. Then:

shut down: π(0) = −F produce q: π(q) = p·q − VC(q) − F produce beats shutdown ⇔ p·q − VC(q) ≥ 0 ⇔ p ≥ AVC(q)

The firm asks one question: does revenue cover the costs I can avoid? The shutdown price is the minimum of AVC. A firm can rationally produce while making a loss.

From choices to the supply curve

Solve the firm’s problem at every price and write down the quantity. That schedule is the supply curve, exactly like collecting optimal consumption at each price gave demand in Unit 1. For C(q) = F + 2q + q²:

MC = 2 + 2q, AVC = 2 + q ⇒ shutdown price = min AVC = 2 qs(p) = 0 if p ≤ 2, qs(p) = (p − 2)/2 if p > 2 e.g. p = 4 → 1, p = 6 → 2

A price change moves you along the supply curve. A change in costs shifts it.

Market supply: add quantities at the same price

Firm A has MCA = 2 + 2qA, firm B has MCB = 4 + 2qB. Then qsA = (p − 2)/2 and qsB = (p − 4)/2 for p above 4, else 0. Market supply is the horizontal sum: at p = 6, Q = 2 + 1 = 3. Same trick as market demand in Unit 1.

Long run: the value of flexibility, and scale

In the long run the firm also chooses its plant. Because it could always keep the old plant, flexibility can never raise the cost of a given output:

CLR(q) = min over K of CSR(q; K) ⇒ CLR(q) ≤ CSR(q; K̄) for every q

Worked numbers: q = √(LK), w = r = 1

1

Short-run average cost with plant K: SRAC(q; K) = K/q + q/K.

2

Choose the best K at each q: derivative in K is 1/q − q/K² = 0, so K = q.

3

Then SRAC = 1 + 1 = 2. So LRAC = 2, flat, and CLR = 2q. Check against the formula 2q√(wr) = 2q ✓.

Explorer · Scale and long-run average cost

Trap

“The long run implies a U-shaped LRAC.” No. The definition of the long run (all inputs adjustable) does not imply any shape. With constant returns, LRAC is flat. U shapes need a technology that first has increasing and later decreasing returns.

Shutdown versus exit, and what “profit” really means

Short run: does production cover avoidable costs? Long run: the firm can release everything, so it produces only if some q covers all economic costs: p ≥ min LRAC.

Economic cost includes the value of what your own resources could earn elsewhere. Example (Exercise 12c): revenue 100, purchased inputs 60. Accounting profit = 40. But the owner’s time could earn 25 and the premises could be rented for 20. Economic profit = 40 − 25 − 20 = −5, so the owner is better off taking the outside options. Zero economic profit means every resource, including the owner’s, earns exactly what it could earn elsewhere. It is not “making nothing”.

(c) Why a before–after comparison from (high, no charge) to (low, charge) does not isolate the charge. (d) Should construction enter? Produce this year but not renew?
Step-by-step solution

(b) Low price: yes. Removing the charge moves the plant from −20 to +10, so it renews. High price: no closure either way, so removal changes profit (+30) but prevents nothing.

(c) The move from (high, no charge) to (low, charge) changes price and the charge at once: contribution falls 120 → 40. It cannot tell how much comes from each. The table separates them: the price change alone lowers it by 50, and the charge alone by 30 (at either price).

1. Which way to produce? (5 points)

A firm has technology q = √(LK) and must produce q = 8.
(a) Labour costs w = 1 and capital r = 4. Find the cost-minimising bundle and the minimum cost. (2)
(b) The price of capital rises to r = 9, with w = 1. Find the new cost-minimising bundle and cost. What would the old bundle cost at the new prices, and how much does substitution save? (2)
(c) Does this calculation tell us whether the firm should produce 8? What more is needed? (1)
Answer key and marking

(a) K/L = w/r = ¼ ⇒ L = 4K. LK = 64 ⇒ 4K² = 64 ⇒ K = 4, L = 16. Cost = 16 + 4·4 = 32. (Check: 2q√(wr) = 16·2 = 32.)

(b) K/L = 1/9 ⇒ L = 9K; 9K² = 64 ⇒ K = 8/3, L = 24. Cost = 24 + 9·(8/3) = 24 + 24 = 48. Old bundle (16, 4): 16 + 36 = 52. Saving = 52 − 48 = 4. Less capital (4 → 2.67), more labour (16 → 24).

(c) No. Cost minimisation takes q as given. We also need the selling price p and the marginal cost (here C = 2q√(wr) is linear, so MC is constant) to choose how much to produce.

2. Choosing output (4 points)

A price-taking firm has q = (LK)1/4, w = 1, r = 4, p = 16. Both inputs adjust; there are no other costs or capacity limits.
(a) Find the conditional input demands, C(q) and MC(q). (2)
(b) Find the profit-maximising output, input quantities and profit. Check that producing beats zero output. (1.5)
(c) The price falls to 8. What is the new output and profit, and what does not change? (0.5)
Answer key and marking

(a) K/L = w/r = ¼ ⇒ L = 4K. LK = q⁴ ⇒ 4K² = q⁴ ⇒ Kc = q²/2, Lc = 2q². C = 1·2q² + 4·q²/2 = 4q²; MC = 8q. (Check with the formula C = 2q²√(wr) = 2q²·2 = 4q² ✓.)

(b) p = MC: 16 = 8q ⇒ q* = 2 (MC rising, so a maximum). L = 2·4 = 8, K = 4/2 = 2. Profit = 16·2 − (8 + 4·2) = 32 − 16 = 16 > π(0) = 0.

(c) p = 8: q* = 1, L = 2, K = ½, profit = 8 − (2 + 2) = 4. The cost function C = 4q² does not change.

3. Short-run costs (4 points)

q = √(L·K̄) with K̄ = 6, w = 4, r = 1. The capital payment is unavoidable.
(a) Find the labour needed for output q, then F, VC(q) and C(q). (1)
(b) Compute AFC, AVC, AC and MC at q = 3. (1)
(c) At which output is AC lowest? Verify MC = AC there. (1)
(d) At p = 3 find the best output and profit. Compare with shutting down. (1)
Answer key and marking

(a) L = q²/6. F = rK̄ = 6. VC = 4·q²/6 = 2q²/3. C = 6 + 2q²/3.

(b) At q = 3: AFC = 6/3 = 2, AVC = 2·3/3 = 2, AC = 4, MC = 4q/3 = 4.

(c) AC = 6/q + 2q/3 ⇒ −6/q² + 2/3 = 0 ⇒ q² = 9 ⇒ q = 3. AC = 4 = MC ✓.

(d) MC = 4q/3 = 3 ⇒ q* = 9/4 = 2.25. Revenue 6.75. Cost = 6 + (2/3)(2.25)² = 6 + 3.375 = 9.375. Profit = −2.625 (= −21/8). Shutdown: −F = −6. So produce at a loss: the loss is smaller than the unavoidable −6. (Also AVC(2.25) = 1.5 < 3 < AC ≈ 4.17.)

A plant’s best annual operating contribution after re-optimising output is: high price and no charge 100; high price with charge 70; low price and no charge 55; low price with charge 25. Renewal requires an avoidable payment of 50. Past construction cost 300, unrecoverable. Closing gives zero.

2. Constant marginal cost and capacity (4 points)

A firm’s minimum cost is C(q) = 6q for q ≥ 0, with capacity q ≤ 10 and no other costs.
(a) Find the optimal output and profit at p = 5, 6, 7. (2)
(b) Why does p = MC not determine output when p = 6? (1)
(c) Why does the optimum at p = 7 not satisfy p = MC? (1)
Answer key and marking

(a) π = (p − 6)q. p = 5: q = 0, profit 0. p = 6: profit 0 for every q in [0, 10]. p = 7: q = 10 (capacity), profit 10.

(b) MC = 6 at every output, so p = MC holds at all q (or none). It does not pick one.

(c) At p = 7, p > MC = 6 everywhere, so profit rises with q until capacity binds. The optimum is a corner determined by the constraint, not by p = MC. Without a capacity limit there would be no finite optimum.

The decision flow

1. What is fixed? Output target → cost minimisation. Price → output choice.
2. Both inputs free? Use MRTS = w/r (or a corner for linear and kinked technologies). One input fixed? Solve the target for the free input directly.
3. Output choice: p = MC on rising MC; apply capacity; compare with zero (or with −F).
4. Open or closed? This period: p vs AVC. Next period: S vs avoidable F. Long run: p vs min LRAC.
5. Interpret in one sentence, naming the idea.

Twelve traps that cost points

1 · Tangency gives only a ratio

Always use the output target to find the size.

2 · Falling MP ≠ falling output

MP is still positive, so output still rises.

3 · Diminishing MP ≠ decreasing returns to scale

One input versus all inputs.

4 · Higher output per worker ≠ better technology

It can be more capital per worker.

5 · Fixed cost does not move MC, AVC or supply

It raises AC and lowers profit only.

6 · Fixed ≠ sunk

Fixed: does not vary with q. Sunk: unavoidable now. Next year’s rent is fixed but avoidable.

7 · Use AVC to shut down, AC to measure profit

A firm can produce at a loss when p is between AVC and AC.

8 · Check the right p = MC root

Rising MC only, and p above min AVC.

9 · Corner solutions ignore tangency

Substitutes: cheaper input only. Complements: the kink.

10 · Constant MC leaves scale undetermined

p < MC: zero. p = MC: any q. p > MC: infinite, or capacity.

11 · The long run does not imply a U shape

Returns to scale set the shape of LRAC.

12 · Fuel per unit falling ≠ technology improved

Movement along a curve versus a shift.
