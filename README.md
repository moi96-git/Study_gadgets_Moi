# Unit 3 Quiz Lab

An interactive, single-page study guide for **Unit 3 (production, costs and firm supply)** of *21DM001 · Economics for Data-driven Decision Making*.

Each module goes: idea → why it's true → worked numbers → live explorer → check-yourself questions.

## Modules

| # | Topic | # | Topic |
|---|-------|---|-------|
| 0 | Start here | 7 | Long run & scale |
| 1 | Toolbox (maths) | 8 | Power plants |
| 2 | Production | 9 | Practice solved |
| 3 | Cheapest inputs | 10 | Drills |
| 4 | Cost → output | 11 | Mock quizzes |
| 5 | Short-run costs | 12 | Cheat sheet |
| 6 | Shutdown & supply | | |

## Features

- Interactive SVG explorers (sliders and dropdowns) for isoquants, cost minimisation, cost curves and more
- Multiple-choice checks with instant feedback, drills, flashcards and timed mock quizzes
- Progress tracker in the top bar (saved in your browser only)
- Light/dark theme toggle, responsive layout

## Usage

No build step or dependencies. Open [index.html](index.html) in a browser. An internet connection is only needed for the Google Fonts.
